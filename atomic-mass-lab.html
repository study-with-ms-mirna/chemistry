The rule
  • Atomic number = protons
    It tells you the element.
  • Mass number = protons + neutrons
  • Isotopes = same protons, different neutrons

The rule
  • Relative abundance = how common each isotope is. Together = 100%
  • Contribution = mass × abundance (decimal)
  • Atomic mass = add all the contributions

The rule
  • Atomic number (whole): the protons, the element's ID
  • Atomic mass (decimal): the weighted average of the isotopes
  • It is a decimal because isotopes have different masses and different abundances
